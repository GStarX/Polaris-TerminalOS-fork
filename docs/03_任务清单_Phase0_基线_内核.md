# 03 · 任务清单：Phase 0 / 基线构建 / 内核升级（D 项）

- 状态含义：`done` 已完成且有证据；`blocked` 有明确阻塞；`ready` 可立即开始；`todo` 未开始；`n/a` 不适用
- 真机相关任务（adb / fastboot / 刷写）**只能由首席操作**；其他角色只准备材料与判据。
- 每个任务完成必须留下证据：日志、命令输出、截图、文件校验值。没有证据 = 没完成。
