## 4. 结论

1. **零构建阶段的目标达成**：官方 22.2 + ADB 部署就能做到"开机进 Termux、Home/最近任务出不去、音量/休眠正常、崩溃可恢复"。
2. 两个需求必须回到 ROM 构建/框架补丁：
   - **隐藏底部导航条**：RRO 被系统拒绝，immersive 无效 → 需要 `config_showNavigationBar=false` 的静态 overlay（我们已有 vendor overlay，只缺 ROM 构建）。
   - **锁任务下的快捷设置**：22.2 框架代码不支持，必须打最小补丁（docs/08 已给出候选）。
3. 一个必须修的体验缺口：**管理员维护入口在自动拉起流程下不可达**。
4. 另一个已知限制：当前 Termux/TerminalHome 是 adb 安装的普通应用，恢复出厂会丢；要长期保留必须打 ROM（Phase 2 剩余部分）。
